# Deck layout proposals

Five static mockups of the deck area, two and four decks, with the stems as knobs. Open them
in a browser from this folder: they use the app's own tokens and components. The first one,
"Couloirs", was chosen and is the application's layout (see `../DESIGN.md`); the others are
kept for the record.

| File | Idea |
| --- | --- |
| `1-couloirs.html` | One horizontal band per deck holding everything about it, the pitch fader at its end. |
| `2-ailes.html` | Decks in columns at the screen's edges, like the turntables; waveforms and library in the middle. |
| `3-dock.html` | Compact deck rows; one dock below plays the deck in focus. |
| `4-console.html` | Waveforms across the top, deck columns below, the internal mixer as a console in the middle. |
| `5-couloirs-epure.html` | Proposal 1 stripped to what is read between two gestures, for a controller in hand. |
