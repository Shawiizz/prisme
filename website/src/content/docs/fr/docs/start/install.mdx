Prisme est gratuit. Les paquets pour Windows, macOS et Linux sont joints à chaque version sur la [page des releases GitHub](https://github.com/Shawiizz/prisme/releases/latest) ; pour l’instant, la version Android se compile depuis le code source.

## Ce qu’il vous faut

| Système | Version | Paquet |
| --- | --- | --- |
| Windows | Windows 10 ou 11, 64 bits | Installeur, `…-windows-x64.exe` |
| macOS | macOS 13.3 ou plus récent, Apple silicon ou Intel | Image disque, `.dmg` |
| Linux | Ubuntu 22.04 ou une distribution aussi récente, x86 64 bits | `.deb` ou AppImage |
| Android | Android 10 ou plus récent, un téléphone ou une tablette ARM 64 bits | Paquet, `…-android-arm64.apk` |

La fenêtre demande au moins 1280 × 640 pixels : un écran de portable 1080p à 150 % de mise à l’échelle suffit. Une carte son à quatre sorties permet d’envoyer chaque deck sur sa propre voie d’une table de mixage ; avec deux, Prisme utilise sa table de mixage logicielle. Voir [Carte son et latence](/fr/docs/start/audio/).

## Installation

<Tabs syncKey="os">
<TabItem label="Windows">

<Steps>

1. Téléchargez `Prisme-…-windows-x64.exe` depuis la [dernière version](https://github.com/Shawiizz/prisme/releases/latest).

2. Ouvrez-le. Windows peut prévenir qu’il a protégé votre ordinateur contre une application non reconnue : choisissez **Informations complémentaires**, puis **Exécuter quand même**.

3. L’installeur ne demande rien : il installe Prisme pour votre seul compte utilisateur, donc sans droits d’administrateur, en français ou en anglais selon votre système, puis ouvre Prisme. Si Prisme est déjà ouvert, il vous demande d’abord de le fermer.

4. Ensuite, lancez Prisme depuis le menu Démarrer. Les nouvelles versions s’installent d’elles-mêmes quand Prisme les propose.

</Steps>

Pour la latence la plus basse, installez le pilote ASIO de votre carte son depuis le site de son fabricant : Prisme propose alors **ASIO** à côté de **WASAPI** dans **Réglages** > **Audio**.

</TabItem>
<TabItem label="macOS">

<Steps>

1. Téléchargez le `.dmg` depuis la [dernière version](https://github.com/Shawiizz/prisme/releases/latest). Il tourne aussi bien sur les Mac Apple silicon qu’Intel.

2. Ouvrez-le et faites glisser **Prisme** dans **Applications**.

3. Ouvrez Prisme. La première fois, macOS refuse, car l’application n’est pas notariée par Apple. Fermez le message.

4. Ouvrez **Réglages Système** > **Confidentialité et sécurité**, descendez jusqu’au message concernant Prisme et choisissez **Ouvrir quand même**. Confirmez.

5. Quand vous configurez vos platines pour la première fois, macOS demande si Prisme peut utiliser le micro : autorisez-le. Prisme lit le timecode de vos disques sur les entrées de votre carte son, et macOS considère toute entrée comme un micro.

</Steps>

<Aside type="caution">
Si vous avez refusé l’accès au micro, les platines n’envoient rien. Autorisez de nouveau Prisme dans **Réglages Système** > **Confidentialité et sécurité** > **Micro**.
</Aside>

</TabItem>
<TabItem label="Linux">

Deux paquets sont proposés :

- **`.deb`** pour Debian, Ubuntu et leurs dérivées. Installez-le avec votre gestionnaire de paquets, ou depuis un terminal :

  ```sh
  sudo apt install ./Prisme-*-linux-x64.deb
  ```

- **AppImage** pour toute autre distribution. Rendez-la exécutable et lancez-la :

  ```sh
  chmod +x Prisme-*-linux-x64.AppImage
  ./Prisme-*-linux-x64.AppImage
  ```

Prisme joue via **ALSA**, qui fonctionne partout, ou via **JACK** pour la latence la plus basse. Sur un système avec PipeWire, les applications JACK passent par PipeWire quand sa prise en charge de JACK est installée (le paquet `pipewire-jack` sur la plupart des distributions). Le choix se fait dans **Réglages** > **Audio** : voir [Carte son et latence](/fr/docs/start/audio/#linux-alsa-et-jack).

</TabItem>
<TabItem label="Android">

<Steps>

1. Sur le téléphone ou la tablette, téléchargez le paquet depuis la [page d’accueil](/fr/#download) ou les [versions sur GitHub](https://github.com/Shawiizz/prisme/releases) : le fichier qui finit par `-android-arm64.apk`.

2. Ouvrez-le. Android vous demande d’autoriser les installations depuis l’application avec laquelle vous l’avez ouvert (le navigateur ou le gestionnaire de fichiers) : autorisez-les, puis installez.

</Steps>

Au premier lancement, Prisme demande à lire votre musique et à envoyer des notifications. Il ne demande à écouter les entrées que lorsque vous configurez des platines. Voir [Téléphone et tablette](/fr/docs/interface/phone/) pour le fonctionnement de l’interface aux doigts.

</TabItem>
</Tabs>

## Votre musique

Prisme lit le dossier de musique de votre système, avec ses sous-dossiers, et le surveille : un fichier copié dedans apparaît dans la bibliothèque et s’analyse en arrière-plan.

| Système | Dossier |
| --- | --- |
| Windows | Votre dossier **Musique**, où qu’il ait été déplacé (un autre disque, OneDrive, un lecteur réseau) |
| macOS | **Musique** dans votre dossier de départ |
| Linux | Votre dossier de musique tel que le définit le bureau (`XDG_MUSIC_DIR`), sinon `~/Music` |
| Android | Le dossier partagé **Music** du téléphone |

Sur ordinateur, vous pouvez choisir un autre dossier dans **Réglages** › **Bibliothèque** › **Dossier de musique**. Plus de détails dans [Ajouter votre musique](/fr/docs/library/adding-music/).

## Mises à jour

Sous Windows, macOS et Linux, Prisme cherche une nouvelle version sur GitHub à chaque démarrage. Quand il y en a une, un bouton **Mise à jour** avec son numéro de version apparaît dans la barre de titre.

- Appuyez dessus quand vous êtes prêt : Prisme télécharge la mise à jour en montrant où il en est, l’installe et redémarre.
- Le bouton est désactivé tant qu’un deck joue ou qu’un disque tourne, puisque l’installation redémarre Prisme. Arrêtez d’abord les decks.
- Pour vérifier à nouveau, ouvrez **Réglages** > **À propos** et appuyez sur **Vérifier maintenant**.

Les mises à jour sont signées : Prisme n’installe que celles publiées par le projet.

Sur Android, Prisme cherche aussi à chaque démarrage, et propose la nouvelle version dans **Réglages** > **À propos** :

- Appuyez sur **Installer** : Prisme télécharge le paquet de la version, puis le confie à l’installeur d’Android, où vous confirmez avec **Installer**. L’installation ferme Prisme : rouvrez-le ensuite.
- La première fois, Android demande votre accord : appuyez sur **Autoriser…**, activez **Autoriser à partir de cette source** dans la page qu’Android ouvre, puis revenez. L’installeur suit.
- Pas pendant qu’un deck joue. Le paquet téléchargé est supprimé une fois installé, ou si vous annulez. Android ne l’installe par-dessus l’ancienne version que s’il est signé par le projet.

## Modèles de séparation

La séparation des morceaux en stems utilise des modèles qui ne font pas partie de l’installeur. Téléchargez-les une fois, quand vous voulez des stems, depuis **Réglages** > **Bibliothèque** : chaque modèle affiche un bouton **Télécharger** avec sa taille. Voir [Stems](/fr/docs/sound/stems/).
